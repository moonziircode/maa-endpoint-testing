## 1. AUTHENTICATION & SSO HANDSHAKE

* **Feature:** Agent Authentication & Session Initialization
* **API Component:** CAS SSO & Anteraja API Gateway (`MaaAgentApi` / `cas.anteraja.id`)
* **Endpoint 1 (Initial Ticket Granting):** `GET /cas/login?isapp=true&acctype=emp` [CONFIRMED]
  - **Method:** `GET`
  - **Auth:** None (Public SSO Portal)
  - **Headers:** `User-Agent: okhttp/4.9.0`, `Accept: text/html...`
  - **Response:** Extracts `lt` (Login Ticket) and `execution` flow state token.
* **Endpoint 2 (Submit Credentials):** `POST /cas/login?isapp=true&acctype=emp` [CONFIRMED]
  - **Method:** `POST`
  - **Auth:** Form UrlEncoded (`username`, `password`, `lt`, `execution`, `_eventId=submit`, `submit=LOGIN`)
  - **Response Headers:** `Set-Cookie: TGC=...; JSESSIONID=...`
* **Endpoint 3 (Service Ticket Grant):** `GET /cas/login?service=https%3A%2F%2Fapi.anteraja.id` [CONFIRMED]
  - **Method:** `GET`
  - **Auth:** Cookie `TGC`
  - **Response Headers:** `Location: https://api.anteraja.id/?ticket=ST-XXXXX-mt`
* **Endpoint 4 (API Gateway Token Exchange):** `POST /user/cas/login` [CONFIRMED]
  - **Method:** `POST`
  - **Auth:** Header `deviceId`, `appKey: MAA`, `appSecret: santuy`
  - **Request Body:** `{ ticket: "ST-...", service: "https://api.anteraja.id", deviceId: "...", appKey: "MAA", appSecret: "santuy" }`
  - **Response Body:** `{ status: 0, info: "OK", content: { token: "Bearer ...", agent_staff_id: "...", nir: "50004786", agent: { shop: { district: "31.74.02", name: "..." } } } }`
  - **State Change:** Session created on API gateway; client issues encrypted HttpOnly `maa_session` cookie.

## 3. SCAN & CLAIM PARCEL VALIDATION

* **Feature:** Barcode / AWB Scanning & Idempotent Claim Verification
* **API Component:** `MaaDropoffApi` / `MaaDropoffCariViewModel`
* **Endpoint 1 (Claim Search & Duplicate Validation):** `GET /maa-task/order/v2/search/{awb}?agent_staff_id={staff_id}` [CONFIRMED]
  - **Method:** `GET`
  - **Auth:** Header `token: [JWT]`, `Authorization: Bearer [JWT]`
  - **Response (Unclaimed):** `{ status: 200, info: "OK", content: [ { waybill_no: "...", ... } ] }` -> Order ready for dropoff.
  - **Response (Already Claimed Duplicate):** `{ status: 400, info: "Order ini sudah pernah di klaim sebelumnya.", content: null }` -> System identifies prior claim and surfaces full manifest from v1 metadata without re-claiming.
* **Endpoint 2 (Parcel Metadata Retrieval):** `GET /maa-task/order/search/{awb}?agent_staff_id={staff_id}` [CONFIRMED]
  - **Method:** `GET`
  - **Auth:** Header `token: [JWT]`
  - **Response:** Full shipment manifest (`shipper_info`, `receiver_info`, `items`, `delivery_price`, `is_cod`).
  - **State Change:** Validates parcel eligibility; prevents double-billing and duplicate operational scans.
